# Consensus + Transcript Providers — Research v1
US Top 100 Earnings Intelligence Platform · Task B
Date checked: **Oct 29, 2026** · Method: public web / vendor pages only. No provider was contacted, trialled, or API-tested.
**Pricing rule applied throughout:** a price is labelled *Vendor-published* only if it was read on the vendor's own pricing page/checkout on the date checked. Everything else is labelled *Third-party reported* (source named) or *Pricing not public / sales-only*. No price has been estimated or interpolated.

---

## 0. The critical question, answered first

The platform needs **consensus as it stood immediately before a past release** — not today's consensus for a past quarter (which has already been revised to the actual). That is a *point-in-time / historized snapshot* capability. It is rare, and most cheap APIs do **not** have it.

| Snapshot grade | Meaning | Providers with evidence |
|---|---|---|
| **A — True point-in-time** | Vendor explicitly states estimates are historized / point-in-time, with revision history preserved | **LSEG I/B/E/S, Zacks (direct), FactSet** (institutional; see caveats), |
| **B — Dated revision anchors** | API returns consensus as of fixed lookbacks (7/30/60/90 days ago) and/or a dated surprise file (estimate paired with the actual it preceded) — workable for recent quarters, not a general as-of-date query | **EODHD Earnings Trends, Finnhub earnings-surprise / calendar history, Benzinga via Massive (surprise fields, history to 2010)** |
| **C — Self-snapshot only** | Current consensus only. You can freeze it yourself *from now on* by polling before each release; you **cannot** recover the pre-release consensus for quarters that already reported | **FMP, Alpha Vantage, Finnhub (free/current endpoints), Quartr Pro consensus display** |
| **D — No consensus** | Transcripts/documents only, or fundamentals only | Aiera, EarningsAPI.io / EarningsCalls.dev, Seeking Alpha, Motley Fool, AlphaSense, Tiingo (point-in-time applies to *reported financials*, not estimates) |

> **Practical consequence:** for quarters that reported *before* we subscribe to an A/B provider, the pre-release consensus is **unrecoverable** from a C-grade API. Any backfill for historical quarters must come from an A-grade historized file (LSEG / Zacks / FactSet) or be marked ⚪ NOT AVAILABLE. A C-grade feed is still valid **prospectively**: poll + freeze daily from subscription day forward and the snapshot problem disappears for future quarters.

## 3. Shortlist by budget tier

### Tier 1 — Hobbyist / self-serve API (vendor-published prices, no sales call)
**Recommended stack: FMP Ultimate + EODHD + (transcript specialist if FMP transcripts fail validation)**
- **FMP Ultimate — $99/mo billed annually (vendor-published, Oct 29, 2026).** One key gives: revenue+EPS estimates, earnings calendar, *and* transcripts. This is the only vendor-priced bundle that touches both problems. **Accept its limit explicitly:** consensus is Grade C — start freezing snapshots ourselves, daily, from day one; historical quarters stay ⚪ or use the surprise pairing with a vintage warning.
- **EODHD — Fundamentals from €59.99/mo / All-In-One €99.99/mo (vendor site).** Buy it for one thing: **Earnings Trends 7/30/60/90-day consensus anchors + revision counts** — the cheapest revision-history signal available, and an independent second source for the cross-check rule (FMP vs EODHD consensus disagreement is itself a data-quality flag).
- **EarningsAPI.io / EarningsCalls.dev — $145–$199/quarter tier (vendor-published, but see the ⚠️ price conflict).** Only if FMP transcript quality/timing fails a 5-call validation. Its "minutes after call end" claim and speaker/Q&A segmentation are the best-stated in this tier. Resolve which site/price is authoritative first.
- **Alpha Vantage (already connected, free 25/day):** keep as a third cross-check for EPS surprise on a handful of names, not as infrastructure.
- **Total realistic Tier-1 cost: ~$160–$200/mo** (FMP Ultimate annual-billed + EODHD), plus our own snapshot store. **What Tier 1 cannot do:** recover pre-release consensus for any quarter that reported before we start polling; guarantee transcript quote accuracy; legally *display* data publicly without checking FMP/EODHD display terms (FMP explicitly requires a separate display agreement).

### Tier 2 — Professional (one paid data licence, still no terminal)
**Recommended: Zacks direct *or* Intrinio-Zacks (choose after the point-in-time trial question) + Quartr API *or* Aiera for transcripts**
- **Zacks Earnings Estimates (direct)** is the only non-terminal product with an explicit *"fully historized, preserving point-in-time snapshots"* + full revision-history claim, with EPS history to 1982 / sales to 2000, delivered by API/CSV/SFTP. That claim is exactly the platform's V2 requirement. **Pricing is sales-only — get the quote; do not assume it is cheap.**
- **Intrinio-Zacks** is the same underlying Zacks content through a developer-friendly API (documented EPS/sales estimate + surprise endpoints with date filters). Shortlist it *iff* Intrinio confirms in writing that its estimates are as-of/point-in-time and not current-vintage overwrites. If it cannot confirm, buy Zacks direct.
- **Transcripts: Quartr API** (transcripts + slides + filings + live, one API, MCP included with Pro) **or Aiera** (best-documented transcript API, real-time + historical endpoints). Both sales-only on price. Pick Quartr if slides/filings consolidation matters; pick Aiera if intraday transcript latency matters.
- **Benzinga via Massive ($79/mo annual-billed, individual)** is a legitimate Tier-2 *add-on* for earnings-date confirmation status, guidance records and a 2010-back surprise history — but upgrade to its business tier before displaying anything, and don't mistake its stored estimate for a proven point-in-time freeze.
- **Budget guidance:** no vendor-published prices exist for the core Tier-2 items, so a number cannot be honestly stated. Expect a sales process and an annual contract; get Zacks/Intrinio and Quartr/Aiera quotes in parallel and compare on (a) point-in-time wording in the contract, (b) display/redistribution rights, (c) Top-100 coverage completeness.

### Tier 3 — Institutional (correctness over cost)
**Recommended: LSEG I/B/E/S (+ LSEG transcript content) *or* FactSet Estimates + FactSet Events & Transcripts**
- **LSEG I/B/E/S** has the deepest evidenced history (US from 1976), the broadest contributor/measure set, an API with intraday updates, and explicit point-in-time support in its Actuals/Estimates catalogue. It is the consensus of record used by the wires the platform cross-checks against.
- **FactSet** is the alternative single-vendor answer: Estimates (20+ yrs, surprise, guidance) + a separately licensed Transcripts dataset, one relationship. Its gap is diligence, not capability: get the point-in-time/as-of wording confirmed in the data dictionary before signing, because public docs in this pass did not state it as plainly as LSEG/Zacks.
- **S&P Capital IQ / Visible Alpha** belongs on the Tier-3 long-list for KPI-level consensus depth (pharma/semis/segment KPIs), but in this pass its public evidence was the thinnest of the three — it should not be shortlisted until S&P supplies its API + point-in-time documentation.
- **Bloomberg** only makes sense if a Terminal seat is already paid for for other reasons; B-PIPE/Data License are separate enterprise licences, and its public point-in-time consensus evidence was not verifiable. **AlphaSense** is an optional Tier-3 *research layer*, not a data feed for this platform.
- **Budget guidance:** third-party reports cluster in the ~$10k–$32k/seat/yr range across FactSet/LSEG/Bloomberg/AlphaSense, with wide variance and heavy negotiation — **these are not quotes**. Institutional procurement should budget a five-figure annual commitment per vendor and a multi-week sales cycle.
